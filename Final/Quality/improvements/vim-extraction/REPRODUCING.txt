1. Get both versions
Run in a new directory, not your existing Gemini CLI clone:
  git clone --depth 3 --single-branch --branch experiment/vim-extraction https://github.com/konklewski/gemini-cli-capstone-analysis.git gemini-vim-after
  git -C gemini-vim-after worktree add --detach ../gemini-vim-before 8f0a0f2d7d827d7ccd11c3df89631c39af67296f
  git -C gemini-vim-before rev-parse HEAD
  git -C gemini-vim-after rev-parse HEAD

The last commands should print the before and after IDs above. Source/test
SHA-256 values are in experiment.json; check them with shasum -a 256.

Bundle fallback, also in a new directory:
  VIM_EVIDENCE="/absolute/path/to/vim-extraction"
  git clone --depth 1 --single-branch --branch v0.64.0 https://github.com/google-gemini/gemini-cli.git bundle-before
  git -C bundle-before bundle verify "$VIM_EVIDENCE/vim-extraction.bundle"
  git -C bundle-before fetch "$VIM_EVIDENCE/vim-extraction.bundle" 1820eca22b026d6f16c05cc62e845c849aa2f49c:refs/heads/experiment/vim-extraction
  git -C bundle-before switch --detach 8f0a0f2d7d827d7ccd11c3df89631c39af67296f
  git -C bundle-before worktree add --detach ../bundle-after 1820eca22b026d6f16c05cc62e845c849aa2f49c

The bundle requires the baseline commit and preserves both exact revisions.
Patches are provided for review; git am may produce different commit IDs.
